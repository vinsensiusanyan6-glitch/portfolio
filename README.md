# Portfolio Website Template

## Cara menjalankan
Cukup buka file `index.html` menggunakan browser.

## Cara mengubah isi
- Profil: edit bagian About Me di `index.html`
- Project: edit setiap `<article class="project-card">`
- Detail popup project: edit object `projects` di `script.js`
- Warna dan desain: edit variabel di bagian atas `style.css`
- Kontak: ganti email, LinkedIn, GitHub

## Publikasi gratis
Template ini bisa di-upload ke GitHub lalu di-deploy ke GitHub Pages atau Cloudflare Pages.

Catatan: jangan masukkan data sensitif customer seperti password, IP internal, serial number, atau informasi rahasia.
